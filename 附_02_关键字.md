* 内置关键字（语法保留字

| 关键字                             | 说明                                                      |
| ------------------------------- | ------------------------------------------------------- |
| `if`, `elseif`, `else`, `endif` | 条件判断                                                    |
| `foreach`, `endforeach`         | 循环遍历列表                                                  |
| `while`, `endwhile`             | 循环条件                                                    |
| `function`, `endfunction`       | 定义函数                                                    |
| `macro`, `endmacro`             | 定义宏                                                     |
| `return`                        | 从函数/宏中返回                                                |
| `break`                         | 跳出循环（`foreach`/`while`）                                 |
| `continue`                      | 跳过循环剩余部分                                                |
| `set`                           | 设置变量                                                    |
| `unset`                         | 取消变量设置                                                  |
| `list`                          | 列表操作                                                    |
| `string`                        | 字符串操作                                                   |
| `math`                          | 数学表达式计算                                                 |
| `file`                          | 文件操作                                                    |
| `cmake_minimum_required`        | 指定 CMake 最低版本                                           |
| `project`                       | 定义项目名称和语言                                               |
| `include`                       | 包含 CMake 模块文件                                           |
| `find_package`                  | 查找并加载外部包                                                |
| `add_executable`                | 添加可执行文件目标                                               |
| `add_library`                   | 添加库目标                                                   |
| `add_subdirectory`              | 添加子目录                                                   |
| `target_*` 系列命令                 | `target_include_directories`, `target_link_libraries` 等 |
| `install`                       | 安装规则                                                    |
| `enable_testing`, `add_test`    | 测试相关                                                    |

* 上下文关键字

| 关键字         | 说明              |
| ----------- | --------------- |
| `PRIVATE`   | 设置仅当前目标可见，不传递   |
| `PUBLIC`    | 当前目标可见且传递至依赖者   |
| `INTERFACE` | 仅传递至依赖者，当前目标不使用 |

* 目标属性关键字

| 关键字                         | 说明                   |
| --------------------------- | -------------------- |
| `PROPERTIES`                | 标记开始设置属性列表           |
| `BUNDLE`                    | 属性名：是否为 macOS Bundle |
| `POSITION_INDEPENDENT_CODE` | 属性名：是否 PIC           |
| `CXX_STANDARD`              | 属性名：C++ 标准           |
| ...                         | 大量其他属性名（可在文档中查）      |

* install/Export关键字

| 关键字                                           | 说明              |
| --------------------------------------------- | --------------- |
| `DESTINATION`                                 | 安装目标路径          |
| `RUNTIME`                                     | 可执行文件 / DLL     |
| `LIBRARY`                                     | 共享库             |
| `ARCHIVE`                                     | 静态库 / 导入库       |
| `BUNDLE`                                      | macOS Bundle 包  |
| `FRAMEWORK`                                   | macOS Framework |
| `PRIVATE_HEADER`, `PUBLIC_HEADER`, `RESOURCE` | 额外文件分类          |
| `EXPORT`                                      | 导出目标集（用于其他项目引用） |

* ### `find_package` 和 `find_*` 命令中的关键字

| 关键字                               | 说明                     |
| --------------------------------- | ---------------------- |
| `REQUIRED`                        | 必须找到，否则报错              |
| `QUIET`                           | 静默模式，不输出消息             |
| `MODULE`                          | 仅使用 CMake 模块文件搜索       |
| `CONFIG`                          | 仅使用 xxxConfig.cmake 文件 |
| `NO_MODULE`                       | 不使用模块模式                |
| `COMPONENTS`                      | 指定需要的组件                |
| `OPTIONAL_COMPONENTS`             | 可选组件                   |
| `EXACT`                           | 版本号必须精确匹配              |
| `PATHS`, `HINTS`, `PATH_SUFFIXES` | 搜索路径修饰符                |
